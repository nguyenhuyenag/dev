
- BETWEEN thì bao gồm hai đầu, nhưng với ngày giờ, hãy cẩn thận kẻo mất ngày cuối.

- BETWEEN với ngày tháng:

	+ DATE:
	
		SELECT * FROM orders
		WHERE order_date BETWEEN '2024-01-01' AND '2024-01-31'; // [1/11 - 31/1] -> Đúng
		
	+ DATETIME / TIMESTAMP:
	
		SELECT * FROM orders
		WHERE order_time BETWEEN '2024-01-01' AND '2024-01-31';
		
		→ Câu này NGẦM HIỂU là:

		WHERE order_time >= '2024-01-01 00:00:00'
		  AND order_time <= '2024-01-31 00:00:00' // CHỈ ĐẾN 00:00:00!

		→ Mất hết dữ liệu của ngày 31/1 (từ 00:00:01 đến 23:59:59)!
	
	=> Cách đúng:
	
		-- Cách 1: Dùng < ngày kế tiếp:
		
			WHERE order_time >= '2024-01-01'
			  AND order_time <  '2024-02-01';

		-- Cách 2: Mở rộng đến cuối ngày:
		
			WHERE order_time BETWEEN '2024-01-01 00:00:00'
								 AND '2024-01-31 23:59:59';
	
	=> Dùng BETWEEN cho số, dùng >= AND < cho ngày giờ
