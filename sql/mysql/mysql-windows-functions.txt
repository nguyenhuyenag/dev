
1. ROW_NUMBER: Đánh số thứ tự của các dòng trong cùng 1 tập kết quả:
	=> 2 hàm giống nhau:
	
		ROW_NUMBER() OVER (
			PARTITION BY <cột nhóm>	// Chia nhóm theo cột nào và đánh số từ 1. Nếu không có thì sẽ lấy cả bảng
			ORDER BY <cột sắp xếp> 	// Cột sẽ quyết định số thứ tự
		)
		
	=> Bắt buộc phải có ORDER BY trong OVER() — nếu không, thứ tự đánh số là không xác định.
	
	-- Ví dụ: Ta có bảng activity:
	
		player_id|device_id|event_date|games_played|
		---------+---------+----------+------------+
				1|        2|2016-03-01|           5|
				1|        2|2016-03-02|           6|
				2|        3|2017-06-25|           1|
				3|        1|2016-03-02|           0|
				3|        4|2018-07-03|           5|
		
		-> Tìm ngày đăng nhập đầu tiên:
			select
				player_id,
				event_date,
				games_played,
				ROW_NUMBER() over (
					PARTITION by a.player_id
					order by a.event_date 
				) as 'rn'
			from activity a;
		
		=> Ta sẽ được:
			player_id|event_date|games_played|stt|
			---------+----------+------------+---+
					1|2016-03-01|           5|  1|
					1|2016-03-02|           6|  2|
			---------+----------+------------+---+
					2|2017-06-25|           1|  1|
			---------+----------+------------+---+
					3|2016-03-02|           0|  1|
					3|2018-07-03|           5|  2|
		
		=> Sau đó chỉ cần lấy dòng 'rn = 1':
		
			select 
				t.player_id,
				t.event_date as 'first_login'
			from (
				select
					player_id,
					event_date,
					row_number() over (
						partition by player_id
						order by event_date
					) as 'rn'
				from activity
			) t
			where t.rn = 1;

2. RANK(), DENSE_RANK(): Tương tự ROW_NUMBER nhưng có một chút khác biệt:

		Hàm            | Trùng giá trị               | Ví dụ kết quả
		---------------|-----------------------------|------------------
		ROW_NUMBER()   | Đánh số khác nhau           | 1, 2, 3, 4
		RANK()         | Cùng hạng, nhảy số          | 1, 2, 2, 4
		DENSE_RANK()   | Cùng hạng, không nhảy       | 1, 2, 2, 3
		---------------|-----------------------------|------------------

	=> 	ROW_NUMBER 			= Đánh stt không trùng.
		RANK, DENSE_RANK 	= Xếp hạng

3. Các hàm lấy giá trị theo thứ hạng
		Hàm               | Lấy gì
		------------------|-------------------------------------------------
		FIRST_VALUE()     | Giá trị đầu tiên trong cửa sổ và lặp lại giá trị đó trên mọi dòng của partition
		LAST_VALUE()      | Giá trị cuối cùng (cần ROWS BETWEEN ... UNBOUNDED FOLLOWING)
		NTH_VALUE(col, N) | Giá trị thứ N trong cửa sổ
	
	-- Ứng dụng
	3.1. So sánh lương của người cao nhất phòng với các thành viên còn lại

	3.2. Lấy người có lương thấp nhất mỗi phòng ban
		select 
			*,
			LAST_VALUE(e.salary) over (
				partition by department
				order by salary desc
				ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING
			) as 'luong_thap_nhat'
		from employees e;
	
	> Lưu ý: LAST_VALUE(), NTH_VALUE() rất dễ sai vì cửa sổ mặc định là:
			
			ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW 		 -> Cửa sổ chỉ tính từ đầu partition đến dòng hiện tại.
		Cần phải sửa lại:
			ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING -> Nhìn toàn bộ partition

3. LAG/LEAD: Lấy giá trị của dòng TRƯỚC đó, SAU đó.
		LAG(<cột>,				// Cột cần lấy giá trị
			<offset>,			// Lùi bao nhiêu dòng, mặc định là 1
			<giá_trị_mặc_định>	// Trả về gì nếu không có dòng trước, mặc định là NULL
		) OVER (
			PARTITION BY <cột nhóm>
			ORDER BY 	 <cột sắp xếp>
		)
		
	-- Ví dụ
	3.1: Tính doanh thu trên với ngày trước đó
		date      |revenue|
		----------+-------+
		2024-01-01|    100|
		2024-01-02|    150|
		2024-01-03|    120|
		2024-01-04|    200|
		----------+-------+
				
		SELECT 
			date,
			revenue,
			 CONCAT(IF(diff > 0, '+', ''), diff) AS daily_revenue
		FROM (
			SELECT 
				date,
				revenue,
				revenue - LEAD(revenue, 1, 0) OVER (ORDER BY date) AS diff
			FROM DailyRevenue
		) t;
		
		=> Sẽ cho ra kết quả:
			date      |revenue|daily_revenue|
			----------+-------+-------------+
			2024-01-01|    100|          100|
			2024-01-02|    150|           50|
			2024-01-03|    120|          -30|
			2024-01-04|    200|           80|
